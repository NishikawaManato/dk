# 概要 (Overview)
趣味で作成したプログラムやスクリプトを保管・管理するための個人的なリポジトリです。
主に画像処理や色に関する実験、検証用のコードが含まれています。

# 使用技術 (Environment)
- Python (OpenCV, NumPyなど)
- C
